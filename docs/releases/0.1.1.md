# svnbox 0.1.1

A small update to panel dividers and version information.

- Remove colored highlights when hovering over or dragging the navigation, inspector, and diff dividers.
- Keep the navigation resize handle above the status bar, preventing the divider from extending through it.
- Preserve mouse resizing and keyboard navigation, with a compact keyboard focus indicator.
- Show the installed app version correctly in the About window.

Available for Apple Silicon Macs running macOS 13 or later. The interface is currently in Simplified Chinese.
