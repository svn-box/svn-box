# svnbox 0.1.5

Browse remote repositories in a compact, expandable file tree.

- Expand folders in place with consistent indentation, file-type icons, and columns for the last revision, date, and author.
- Show loading progress on the folder being opened. Other folders remain interactive, with individual cancellation and inline retry for failed or stopped reads.
- Preserve the loaded tree when a directory is empty or fails to load, and cancel pending reads when collapsing folders or switching repositories.
- Save bookmarks and check out the selected directory. Selecting a file disables directory actions, preventing a checkout of the previously selected folder.
- Navigate remote folders with the keyboard and keep large directory listings responsive with virtualization.
- Join the path bar and tree cleanly with square upper corners on the content area and rounded lower corners.

Available for Apple Silicon Macs running macOS 13 or later. The interface supports English and Simplified Chinese.
