# 仓盒 0.4.3

- CI 改为 PR／手动触发，发布标签独立完成一轮检查，避免同时推送主分支和标签时重复验收。共用构建准备，正式前端与签名安装包各构建一次，原生回归复用正式前端，临时发布产物保留 1 天。
- 软件更新集中到侧栏上方按钮与原生菜单，设置中移除更新页，仅保留版本信息。
- 主动检查后自动后台下载，按钮原位显示环形进度，关闭提示后继续下载；支持取消与重试，校验完成后再选择“稍后”或“重启以更新”。安装前继续保存提交草稿并检查 SVN 操作与持久化写入。

适用于 macOS 13.3 及以上的 Apple Silicon Mac。Tauri 版用户可通过应用菜单检查更新；Electron 用户需要手动下载安装一次。
