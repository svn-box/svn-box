# svnbox 0.1.2

English support, in-app updates, and a wider navigation sidebar.

- Switch instantly between English and Simplified Chinese in Settings → General → Language. Your choice is restored when you reopen the app.
- Localize the interface, native menus, notifications, error messages, and date formatting while preserving repository paths, commit messages, and SVN command output.
- Keep commit drafts, selected files, working-copy context, and unsaved tool settings intact when switching languages.
- Check for new versions from the application menu or Settings. Download an update when ready, then restart to install it after running SVN operations finish.
- Start the navigation sidebar at 280 px, with mouse resizing and keyboard controls retained.

Available for Apple Silicon Macs running macOS 13 or later. Subversion is bundled with the app; FileMerge is available when Xcode is present.
