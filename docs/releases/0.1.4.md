# svnbox 0.1.4

More reliable local refresh and clearer ways to discard uncommitted changes.

- Offer Discard Local Changes for directories and the working-copy root when their descendants have changes, even if the directory itself is unchanged.
- Keep the actual discard scope visible for review and require confirmation before execution. Paths outside a selected directory remain untouched.
- Clarify the distinction between discarding local edits and restoring historical content, in both English and Simplified Chinese.
- Refresh the current working copy’s local status when returning to the app. Repeated focus events are coalesced; scans wait for writes and reuse fresh results without polling remote repositories.
- Put update status and controls on a dedicated App Updates page in Settings. The application menu opens that page directly.
- Preserve project context, drafts, and update feedback when switching projects during background operations.

Available for Apple Silicon Macs running macOS 13 or later. The interface supports English and Simplified Chinese.
