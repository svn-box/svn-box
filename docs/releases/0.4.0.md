# 仓盒 0.4.0

- 保留现有 React 界面，将 Electron 和 Node 原生逻辑完整迁移到 Tauri / Rust，使用系统 WebKit。
- 保留多仓库、工作副本、历史、差异、选择性提交、冲突处理、文件备份、草稿与凭据作用范围。
- 原生菜单提供“检查更新”，更新包验证签名与版本，存在 SVN 写操作时暂缓安装。
- 首次启动复制导入 Electron 工作区与恢复数据，保留旧配置；密码需重新输入一次，随后保存到 macOS 钥匙串。
- 应用适用于 macOS 13.3 及以上的 Apple Silicon Mac。

Electron 用户需要手动下载安装 Tauri 版一次。后续 Tauri 版本可通过应用菜单检查并安装更新。
