# svnbox 0.1.6

More room for your files and a more consistent Settings layout.

- Start the local diff panel at its minimum height of 150 px, leaving the remaining workspace for the file list. Drag the divider upward whenever you need more room to compare changes.
- Keep the diff panel compact when resizing the window, with drag limits based on the available workspace.
- Align the top of General, Tools, and App Updates in Settings, and give their headings a consistent line height.
- Make the selected Settings category clearer with the theme's accent color, and strengthen the distinction between headings and descriptions.

Available for Apple Silicon Macs running macOS 13 or later. The interface supports English and Simplified Chinese.
