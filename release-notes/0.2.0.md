# svnbox 0.2.0

Recover file contents and resolve common text conflicts without leaving your workspace.

- Compare two repository revisions, or a revision with the working copy, using the built-in unified or side-by-side diff. Open the comparison from a file context menu or a commit's inline diff.
- Recover an existing versioned file from a chosen revision. Review the overwrite, including local edits, before confirming. Recovery changes file contents only and never commits automatically or changes the working copy baseline.
- Keep a local backup before each content overwrite. Review and restore backups from the version dialog, including after restarting svnbox. Binary recovery preserves original bytes, with an explicit unavailable-preview state.
- Resolve common text conflicts by keeping the complete pre-update local file or accepting the complete incoming file, with a preview and confirmation.
- Open FileMerge with actual base, local and incoming snapshots and a separate merge output. Return to svnbox to check, review and apply the result. Closing or cancelling the tool never marks a conflict resolved.
- Reject stale confirmations, changed conflict sources, unsaved merge results and remaining standard conflict markers. All writes use the working copy's operation queue and appear in its logs.
- Refresh backup lists and working-copy comparisons after file operations, including when reopening the version dialog. Incomplete saved records no longer block other backups or merge sessions.
- Respect read-only files during recovery and recheck write access immediately before replacing contents.
- Start the bottom diff panel at 300 px while retaining its adjustable minimum height.

Content recovery supports existing regular files up to 32 MiB. Historical properties, directory restoration, reconstruction of deleted files and move relationships are outside this release. Text conflict actions support UTF-8 files; property, tree and binary conflicts continue to require manual handling. FileMerge requires Xcode; other configured tools open the snapshots and output for manual editing.

Available for Apple Silicon Macs running macOS 13 or later. The interface supports English and Simplified Chinese.
