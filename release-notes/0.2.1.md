# svnbox 0.2.1

- Introduce a new macOS app icon with a full blue background, a translucent archive tray and revision cards.
- Remove the extra inset icon frame and enlarge and center the foreground for clearer Dock presentation.
- Generate standard, dark and tinted appearances from the same transparent foreground in Icon Composer.

Available for Apple Silicon Macs running macOS 13 or later. The interface supports English and Simplified Chinese.
