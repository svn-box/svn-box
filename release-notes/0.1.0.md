# svnbox 0.1.0

The first release of svnbox (仓盒), a Subversion desktop client for macOS.

- Organize multiple repositories, remote bookmarks, and local working copies with groups, favorites, and search.
- Keep file selection, filters, history context, and recoverable commit drafts separate for each working copy.
- Review text and property changes in unified or side-by-side diffs, or open FileMerge.
- Commit selected paths after reviewing the actual scope, update working copies, and browse paginated repository or path history.
- Add, rename, delete, ignore, revert, and clean up files and directories, with explicit confirmation for destructive operations.
- Inspect conflicts, use an external merge tool, and verify the result before marking it resolved.
- Save encrypted credentials for a connection or repository path, browse remote directories, and check out new working copies.
- Follow background operations in searchable logs, cancel tasks, and clear completed records.
- Choose from six modern appearance themes, resize panels, and use keyboard navigation and context menus.

Available for Apple Silicon Macs running macOS 13 or later. The interface is currently in Simplified Chinese. Subversion is bundled with the app; FileMerge is available when Xcode is present.
